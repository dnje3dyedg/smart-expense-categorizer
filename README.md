# 💸 Smart Expense Categorizer

This is a beginner-friendly AI/ML Streamlit app that classifies SMS-based transaction messages into categories like **Food**, **Rent**, and **Travel**, extracts transaction amounts, gives high-spending alerts, and visualizes expenses as a pie chart.

---

## 🚀 Features

- ✅ SMS/Text classification using machine learning
- 💰 ₹ Amount extraction using regex
- 🚨 High spending alert logic
- 📊 Real-time pie chart updates
- 🧠 Trained on custom dataset using `LogisticRegression`
